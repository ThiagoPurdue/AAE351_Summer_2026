# Evaluation and Selection

## The Pugh Matrix
To select the final baseline architecture, competing concepts are evaluated against a set of weighted criteria. The Pugh Matrix is a standard tool where concepts are scored relative to a datum (baseline) design.

## Decision Making Under Uncertainty
Early in the design process, precise performance data is unavailable. Evaluation must account for this uncertainty, often requiring sensitivity analysis to see if changes in assumptions alter the final selection.

## System Integration
Using tools like the Pugh Matrix, you will evaluate competing RCUAV architectures. The evaluation criteria must heavily weight Additive Manufacturing constraints—such as print time, required support structures, and assembly complexity—against aerodynamic efficiency and payload capacity.
