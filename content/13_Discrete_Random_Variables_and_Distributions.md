# Discrete Random Variables

## Probability Mass Functions
A discrete random variable takes on countable values (e.g., number of failed components). The Probability Mass Function (PMF) describes the probability of each specific outcome. 

## The Binomial Distribution
A common discrete distribution in aerospace is the Binomial distribution, which models the number of successes in $n$ independent trials (e.g., the number of successful engine starts out of 100 attempts):

$$ P(X=k) = inom{n}{k} p^k (1-p)^{n-k} $$

## System Integration
Discrete distributions are highly applicable to analyzing the RCUAV's fleet operations, such as predicting the number of failed print jobs out of a batch, or the number of successful cargo deliveries before a major maintenance overhaul is required.
